## 🛠 Технический стек и навыки
* **Платформа:** 1С:Предприятие 8.3 (Управляемые формы, интерфейс "Такси").
* **Сертификация:** Официальный сертификат **[«1С:Профессионал. Платформа 1С:Предприятие 8.3»](https://uc1.1c.ru/account/summary/?token=526279aa64fd6463570dfc58dc8b87f4&ver=2&lang=)**. Активно готовлюсь к сдаче на «1С:Специалист».
* **Кастомизация типовых баз:** Глубокая работа с механизмом расширений. Имею практический опыт безопасного внедрения сложной логики в транзакционный контур проведения через аннотацию `&ИзменениеИКонтроль`. Программная кастомизация UI/UX заимствованных управляемых форм.
* **Архитектура и учет:** Проектирование нетиповых конфигураций с нуля. Внедрение и кастомизация подсистем БСП. Партионный учет (списание по FIFO с контролем остатков в транзакции), кадровые срезы последних, управленческий учет на базе регистров бухгалтерии и планов счетов.
* **Интеграция:** Разработка собственных HTTP-сервисов (JSON), интеграция 1С с Мобильной платформой, парсинг данных из Excel, отладка API через Postman.
* **Инструменты:** Выгрузка конфигураций в исходные файлы, Git (настроенные .gitignore под 1С), написание сложных отчетов на СКД.

## 📂 Мои проекты (Портфолио)

### 1. [Самописная конфигурация «Груминг-салон»](https://github.com/olye28-cloud/Grooming_1C.git)
Комплексная нетиповая база (Мини-ERP) для автоматизации учета в сфере услуг. Развивается более 6 месяцев.
* **Технические особенности:** Ручная интеграция и кастомизация ядра БСП. Реализован партионный учет по методу **FIFO** с транзакционным контролем остатков. Настроен независимый план счетов и регистр бухгалтерии для формирования управленческого баланса (ОСВ на СКД). Разработан кастомный алгоритм расчета сложной заработной платы (оклад + % от личных продаж). 

### 2. [MVP-конфигурация «Салон красоты»](https://github.com/olye28-cloud/BeautySalon_1C.git)
Проект, демонстрирующий навыки интеграции 1С с внешним миром и мобильными устройствами.
* **Технические особенности:** Разработан собственный **HTTP-сервис (JSON)** для обмена данными и мобильное приложение на Мобильной платформе 1С для удаленной записи клиентов (отладка через Postman). Реализован парсинг и пакетная загрузка прайс-листов из файлов Excel. Написан сложный иерархический отчет по продажам на СКД.

### 3. [Кастомное расширение для «1С:Бухгалтерия предприятия 3.0»](https://github.com/olye28-cloud/accounting-extension-1C.git) 
Разработка управленческого контура внутри типовой конфигурации без снятия с поддержки.
* **Технические особенности:** Спроектирован оборотный регистр накопления для учета затрат по статьям ДДС. Логика движений встроена в проведение документов выдачи денег через аннотацию **`&ИзменениеИКонтроль`**, что исключило избыточные запросы к СУБД. Реализована оптимизированная бесконтекстная функция (`&НаСервереБезКонтекста`) с использованием запроса (`РАЗЛИЧНЫЕ`, `УПОРЯДОЧИТЬ ПО`) для динамического сбора и вывода уникальных ставок НДС на заимствованную форму.
